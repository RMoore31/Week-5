# Week-5

This C++ program defines a class Item tp manage inventory items using file input and output.
Each item has a name (string) and a quantity (integar).
To saveToFile() method writes the item's fata to a file name items.txt in the format name, quantity.
The loadFromFile() method reads and displays all item data stored in the file.
In the main() function, an Item object is created, its values are assigned, and both methods are demonstrated.
